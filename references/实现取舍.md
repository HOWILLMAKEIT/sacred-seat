# 实现取舍

## 直接来自知乎原文的语义

- 神圣座位由明确标志触发，并对应一项明确行为。
- 疑似违规时只能判定失败，或将行为永久纳入允许判例。
- RSIP 节点应是局部、具体、可执行的“定式”，不是空泛愿望。
- 低维护成本节点优先沉淀；失败应被视为路径搜索和回滚信号。

## 从 momentum 仓库核对的字段

- CTDP：名称、触发动作、持续时间、当前链长、完成次数、例外规则。
- RSIP：节点名称、可执行规则、父子关系、状态和创建时间。
- 严格模式下可加入“一天最多一条国策”等限制。

## 本项目的独立设计

- 不继承 momentum 的组件、样式、云同步、宠物、押注和社交系统。
- 国策以“上方要求 → 下方目标”展示，更适合阅读因果路径。
- Codex 只返回结构化建议，用户确认后才由应用写入。
- 第一版使用本地持久化；后续再迁移到 SQLite。
